# Pocket Smart AI
Your Smart Budget & Recommendation Assistant

## Features
- Add income and expenses
- Category-wise expense tracking
- Monthly budget
- Dashboard with totals
- Smart rule-based recommendations
- SQLite database
- Flask REST API
- Responsive frontend

## Run
1. Install Python 3.10+
2. Open terminal in this folder
3. `pip install -r requirements.txt`
4. `python backend/app.py`
5. Open http://127.0.0.1:5000

No paid API key is required. The recommendation engine is designed so a Gemini API can be added later.
